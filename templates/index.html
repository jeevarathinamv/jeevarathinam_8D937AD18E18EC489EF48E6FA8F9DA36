Setup & Installation Instructions

1. XAMPP MySQL & Database Setup
  1. Open XAMPP Control Panel and click Start next to Apache and MySQL.
  2. Open browser and go to http://localhost/phpmyadmin/.
  3. Click on Databases tab and create database named: student_course_tracker.
  4. Select student_course_tracker database and click Import tab.
  5. Choose the database.sql file from this project and click Go / Import.
2. VS Code & Python Setup
  1. Open VS Code and choose File > Open Folder to open this project folder.
  2. Open terminal in VS Code (Ctrl + `).
  3. Install required Python packages:
    pip install -r requirements.txt
  4. Run the Flask web application:
    python app.py
  5. Open your web browser at http://127.0.0.1:5000/.
