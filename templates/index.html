Project Setup & Execution Guide

Step-by-step instructions for running this system with XAMPP, VS Code, Python Flask & MySQL

1. XAMPP MySQL Setup
  1. Download and install XAMPP server.
  2. Open XAMPP Control Panel and start Apache and MySQL.
  3. Open browser and go to http://localhost/phpmyadmin.
2. Database Import
  1. In phpMyAdmin, create a database named student_leave.
  2. Click on the Import tab.
  3. Choose the database.sql file from project folder and click Go.
3. VS Code & Python Setup
  1. Open VS Code and navigate to File > Open Folder > project directory.
  2. Open VS Code integrated terminal (Ctrl + `).
  3. Ensure Python 3 is installed on your system.
4. Installation & Running
  1. Install required dependencies:
    pip install -r requirements.txt
  2. Start the application:
    python app.py
  3. Open browser at http://127.0.0.1:5000/
