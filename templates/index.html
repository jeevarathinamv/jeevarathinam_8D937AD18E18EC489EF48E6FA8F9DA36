Project Setup Guide

Simple Steps to Setup & Run the Project

Follow these easy steps to setup XAMPP MySQL, VS Code, and launch the Flask portal.

1
XAMPP MySQL Setup
  • Open XAMPP Control Panel.
  • Start Apache and MySQL modules.
  • Open browser and go to: http://localhost/phpmyadmin
2
Database Import
  • Click Databases tab in phpMyAdmin.
  • Create database named: internship_tracker
  • Click Import tab and select database.sql file.
  • Click Go to execute table creation.
3
VS Code Setup
  • Launch Visual Studio Code.
  • Select File > Open Folder and choose project directory.
  • Open Integrated Terminal: Ctrl + ~
4
Python Package Installation

Run the following command in terminal to install required libraries:

pip install -r requirements.txt
5
Running the Flask Project

Start the Flask application server:

python app.py

Open your web browser and visit: http://127.0.0.1:5000
