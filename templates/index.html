System Quick Setup Guide & Demonstration

1. XAMPP Setup
Start Apache and MySQL in XAMPP Control Panel. Create database campus_recruitment.
2. Import SQL
Import database.sql into phpMyAdmin to create students, recruitment_drives, registrations, and admins tables.
3. Python Dependencies
Open VS Code terminal and run:
pip install -r requirements.txt
4. Run Flask Application
Run python app.py in VS Code.
